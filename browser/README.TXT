                                 ZoolRunner Browser
                                 ==================

This is the Firefox 2 frontend ported to ZoolRunner. ZoolRunner does not make official
releases of the browser at this time, however ZoolRunner Browser builds and is branded.
However,

                                YOU ARE ON YOUR OWN

Please do not submit bug reports to the ZoolRunner project for issues encountered while
attempting to use or build ZoolRunner Browser, unless you know how to and are willing to
submit a fix.

If you find a bug while using ZoolRunner Browser that you suspect to be a layout (Gecko)
issue, please try to replicate it on the latest official release of the ZoolRunner suite.
If the issue also affects the latest offical release, please bring it to our attention.
